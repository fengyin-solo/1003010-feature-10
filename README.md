# 通信基站运维管理平台

面向通信基站站点入网、动力环境监控、天馈巡检、发电保障与退网拆站的一体化基站运维管理后台。

这是一个前后端分离的管理平台：前端 Vue 3 + Vite + TypeScript，后端 FastAPI（Python）。
两边各自独立启动，前端 dev server 已关掉自动打开页面，启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/              统一请求封装
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false）
├── backend/                  FastAPI（Python） 后端
│   ├── app/routers/          每个业务模块一组接口
│   ├── app/services/         业务规则与状态流转
│   └── app/store.py          内存数据仓库与示例数据
├── .gitignore
└── docker-compose.yml
```

## 启动

### 后端

```bash
cd backend
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
./run.sh
```

健康检查：`curl http://127.0.0.1:8000/api/health`

### 前端

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，
需要自己访问。`/api` 由 vite 代理到后端 `http://127.0.0.1:8000`。

## 约定

- 每个模块的前端页面在 `frontend/src/views/<模块>/index.vue`，后端接口在
  `backend/app/routers/<模块>.py`，业务规则在 `backend/app/services/<模块>.py`。
- 列表接口统一返回 `{ items, total, page, size }`，动作接口统一返回 `{ ok, message }`。
- 状态流转只允许在 `app/services` 里改，路由层不做业务判断。

## 电费比对与共站分摊口径

电费管理（`electricbill`）不再只看单月，按站点做横向比对与分摊：

- **环比异常**：同一站点按缴费月份排序，逐月与紧邻的上月账单比对；环比涨幅越过阈值
  （默认 50%，可在 `GET/PUT /api/electricbill/config` 调整）即标「电费异常」，
  明细与异常清单都写明超阈值多少个百分点。首月无比对基准时不判异常。
- **共站分摊**：站点分摊口径是强约束——口径为「分表」时，当月各家读数齐全按分表用电量
  占比分摊（`electricbill_reading`），所有家都没读数时按合同约定比例
  （`electricbill_sharing`）兜底，只有部分家有读数时，有读数的按主表平均单价 × 自家用量
  锁定、剩余金额由缺读数的各家按其合同比例的相对占比分摊；口径为「合同比例」时一律按合同
  比例摊，当月分表读数只作核对。各家分摊合计严格等于账单总额。
- **口径变更**：切换站点分摊口径或调整合同比例后，该站点全部存量账单先按旧口径把分摊
  明细快照进 `electricbill_archive`（历史账单原值留档），再按新口径重算分摊金额；
  账单总额不变，留档可在「重算留档」页签或 `GET /api/electricbill/archive` 查询。
- **状态随明细更新**：缴费 / 核实动作与重算都会刷新综合状态与异常标记；核实确认后账单
  退出待核实清单（可撤销核实）。环比越线站点按站点汇总到
  `GET /api/electricbill/abnormal-sites`，前端「异常待核实」页签即该清单。
